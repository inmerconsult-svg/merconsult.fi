MITÄ TÄMÄ ON
------------
B2B-tilausportaali, ei kuluttajaverkkokauppa eikä kassamaksua.
Hyväksytty yritysasiakas selaa valikoimaa, lisää tuotteita koriin ja
lähettää tilauksen sähköpostitse PDF-liitteellä. Admin käsittelee
tilauksen (laskutus muualla). Ensimmäinen rekisteröitynyt tili on admin.

9. LIIKESÄÄNNÖT
---------------
Hinnat, myyntierä, PDF-datasheet: vain hyväksytty customer|admin.
Vieras ja pending näkevät valikoiman ilman hintoja.

Asiakasnäkymä näyttää tuotteen jos active ja (stock > 0 TAI kelvollinen ETA).
ETA "30.9" / "8.9" = seuraava kyseinen pv.kk (tämä tai ensi vuosi).
Myös 30.9.2026 ja 2026-09-30.

Varasto väreinä, ei lukuina:
  vihreä > 10, keltainen 1–10, punainen 0 + ETA.

Koriin ensimmäinen lisäys = myyntierä (carton_qty). Korissa määrää saa
laskea alle erän (varoitusteksti). 0 / tyhjä kenttä → varmistus ennen poistoa.
Minimitilaus 300 € alv 0 on ehdoton (kori, kassa, palvelin).

Saldo 0 + ETA → rivi merkitään (ENNAKKO) punaisella korissa, tilauksessa,
PDF:ssä ja sähköpostissa. Osatoimitusteksti:
  "Tilauksella on tuotteita jotka saapuvat varastoon myöhemmin.
   Varastossa olevat tuotteet lähetetään osatoimituksena heti."

Tilaus → Neon → Resend PDF-liite myyntiin (settings.order_email, pilkulla
useampi) JA asiakkaalle. Lähdöt erillisiä: toinen ei estä toista.
email_log kirjaa onnistumisen/virheen.

ALV 25,5 % oletus; käännetty verovelvollisuus = 0 %.

Salasanan palautus: /forgot-password → Resend-linkki tilin sähköpostiin
→ /reset-password?token=…

16. TUNNETUT KUOPAT
-------------------
- Zip GitHubissa ≠ lähdekoodi. Vercel lukee kansiot.
- .vercel commit = vanha sivu jää voimaan.
- BETTER_AUTH_URL väärä domain = kirjautuminen ei toimi.
- ORDER_EMAIL_FROM varmennetun domainin ulkopuolelta = Resend hylkää.
- onboarding@resend.dev lähettää vain Resend-tilin omaan sähköpostiin.
- pdf-lib TTF vaatii @pdf-lib/fontkit (package.json + lock).
- Datasheetit private/, ei public/.
- Neon-salasanaa ei saa commitoida.
- mail.ts: merkkijono `/\"/g` + HTML-entiteetti rikkoo `npm run build`.
- order-pdf.ts ei saa tuoda node:fs client-bundleen (fontit: fetch selaimessa, fs vain serverillä).
